## 1. N-way 是否与官方协议一致（VERIFIED）

官方实现（`final_evaluations.ipynb` cell 17）：
```python
r = np.corrcoef(reals, preds)[:N, N:]      # 行=GT，列=重建
congruents = np.diag(r)
success = r < congruents                   # 广播：success[i,j] = r[i,j] < r[j,j]
perf = mean(success.sum(0)) / (N-1)
```
本次复核独立重算（不加载模型，直接用已保存的 1000×1000 `R_*.npy`）：

| 模型 | 重算 acc_A | 既有 acc_A | 重算 acc_B | 既有 acc_B | 一致 |
|---|---|---|---|---|---|
| AlexNet(2) | 0.977492 | 0.977492 | 0.973730 | 0.973730 | ✅ |
| AlexNet(5) | 0.993159 | 0.993159 | 0.989296 | 0.989296 | ✅ |
| InceptionV3 | 0.962539 | 0.962539 | 0.948914 | 0.948914 | ✅ |

- Pearson 相关、对角线为目标、**严格大于**判据、`sum(0)/(N-1)` 归一化 —— 全部与官方一致
- 未使用任何余弦相似度替代

## 2. A/B 候选池一致性（VERIFIED）

- 两个组的 R 矩阵均由**同一个** `GT__<li>__norm.npy` 生成（代码路径唯一）；
- A/B 特征按同一 `ids` 顺序写入（`ids_equal_ref == True`，1000 唯一升序）；
- `R_A` 与 `R_B` 均为 `(1000, 1000)`，索引 i、j 的语义完全相同；
- 982 口径为同一矩阵的前 982 行/列，**A/B 用完全相同的 982 子集**。

## 3. 逐样本计数一致性（VERIFIED）

恒等式推导：`c_j = #{i: R[i,j] < R[j,j]}`，`rank_j = 1 + #{i: R[i,j] ≥ R[j,j]}`（含自身等式）
→ `rank_j = N − c_j + 1`。

实测：`n_rows_csv = 1000`，**mismatch = 0，max|diff| = 0.0**（AlexNet-2 / A_raw）。
同时 `acc = mean_j(c_j)/(N−1)` 与 `delta = mean_j(c_B−c_A)/(N−1)` 与逐样本均值**完全相等**（`delta_mean_from_counts == delta`）。

> 说明：最初草稿把恒等式写成 `rank = N − c`（漏 +1），复核时已被该 1000/1000 的精确比对纠正；**数据本身无误**。

## 4. 排名法检验的适用性（需限定，已补池层面分析）

**问题**：1000 个重建项共享**同一个候选池**（同一个 GT 特征矩阵）→ 各项的 `c_j` 并非独立；Wilcoxon/符号翻转置换在"项可交换"假设下才严格成立，共享池会**高估有效自由度**，进而低估 p 值。

**应对（本轮新增）**：模拟官方"30×300"的做法，做 **20 次随机 300 子池**，每个子池**同时**用于 A 和 B（严格配对），统计池层面的准确率：

| 模型 | A（池均值±sd） | B（池均值±sd） | Δ（池层面） | B 更差的池数 | 池层面 Wilcoxon p |
|---|---|---|---|---|---|
| AlexNet(2) | 0.97744 ± 0.00287 | 0.97383 ± 0.00350 | **−0.00361 ± 0.00183** | **20 / 20** | 1.9e-6（n=20 的精确下限） |
| AlexNet(5) | 0.99318 ± 0.00090 | 0.98940 ± 0.00193 | **−0.00378 ± 0.00148** | **20 / 20** | 1.9e-6 |
| InceptionV3 | 0.96212 ± 0.00514 | 0.94873 ± 0.00626 | **−0.01339 ± 0.00455** | **20 / 20** | 1.9e-6 |

→ 在**尊重候选池共享**的评估方式下，结论不变且更稳健（20/20 池方向一致，池内 sd 远小于效应量）。

**建议的论文表述**：「逐项检验为描述性配对比较；由于共享候选池，显著性以池层面（20×300）重采样结果为准。」

## 6. p = 0 的处理（已修正）

旧 `stats.json` 中 SSE 类指标因 double 下溢写成 `p = 0.0`。本轮改为**对数空间**计算并以下界表达：

| 指标 | 旧表述 | 新表述（Holm 校正后） |
|---|---|---|
| SSIM | p = 0 | **p < 1e-162** |
| PixCorr | p = 0 | **p < 1e-24** |
| EfficientNet-B1 | p = 0 | **p < 1e-10** |
| InceptionV3 | p = 0 | **p < 1e-9** |
| AlexNet(5) | p ≈ 5e-6 | **p < 1e-5** |
| AlexNet(2) | p = 2.5e-4 | **p = 2.57e-4** |

> 数学上不应报告"p 恰好为 0"；这些是浮点下溢，真实值只能给出上界。

## 7. Holm 校正（范围与实现）

- **范围**：P1 全部 6 项指标的 A/B 配对 delta（1000 口径，Wilcoxon 双侧）
- **实现**：在 log10 空间排序后做 Holm：`log10 p_adj(i) = min(0, log10(m−i+1) + log10 p(i))`，并强制单调不增
- **结果**：6/6 仍显著（见上表），因此"P1 结论对多重比较稳健"
